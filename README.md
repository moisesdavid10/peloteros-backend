# Peloteros Backend

Backend oficial de la plataforma **Peloteros**, desarrollado para reserva 
instantánea de canchas deportivas con divididor automático de la cuenta (split bill) e integración de pasarelas de pago digitales

## Tecnologías utilizadas
- **Java 21**
- **Spring Boot**
- **Spring Data JPA / PostgreSQL**
- **Maven**
- **Bruno** (Para pruebas de API)

## Estructura del Proyecto
- `src/`: Código fuente de la API en Spring Boot.
- `Peloteros API Collection/`: Colección de solicitudes de Bruno para probar los endpoints de la API.
